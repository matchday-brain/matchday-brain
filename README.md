# Invictus Outdoor Living - Polished Version

This version is cleaner and more polished:
- Less messy layout
- No huge browser scroll in normal desktop view
- Actual image thumbnails in product cards and basket
- Scenic outdoor kitchen background
- Cleaner central builder
- Default build loaded on open so it looks premium straight away

## Install

Extract into:

```text
C:\apps
```

Then run:

```cmd
cd /d C:\apps\invictus_outdoor_living_polished
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Open:

```text
http://127.0.0.1:5000
```

Admin:

```text
http://127.0.0.1:5000/admin
```

If replacing your current one, copy all files from this folder into:

```text
C:\apps\ce_turner_bbq_builder
```
